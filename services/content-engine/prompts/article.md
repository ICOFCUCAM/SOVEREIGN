# Authoring spec — library guide (Layer 4, /library)

Produce ONE JSON object (or array) matching the `article` schema: slug, title,
dek, category, kicker, readingMinutes, intro[2-3], sections[5×{h,p[2-3],list?}],
keyPoints[4-5], faqs[3×{q,a}], relatedConcepts[3-4], relatedIndustries[3-4],
relatedArticles[2-3], metaTitle, metaDescription.

Depth: ~1100–1500 words. intro 2–3 paragraphs; ~5 sections each a heading + 2–3
paragraphs; 1–2 sections may carry a bullet list. Pillar-quality and genuinely
distinct — no boilerplate shared across articles.

Tone & honesty rules: identical to concept.md. For standards/compliance topics,
say "aligned to ISO 27001 controls", never "ISO 27001 certified".
